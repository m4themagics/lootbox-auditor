# Learning contract

Этот репозиторий существует ради навыка и ради находки, а не ради количества кода. Здесь
единственная в портфеле последовательная статистика — значит, мартингейльная конструкция
должна быть понята и написана автором, а не сгенерирована.

## Когда код считается моим

Модуль можно отметить как освоенный, только если я могу без подсказки:

1. объяснить его вход, выход и invariant;
2. провести маленький пример руками — для e-процесса это пять наблюдений и произведение
   правдоподобных отношений на бумаге;
3. назвать хотя бы один failure mode;
4. сначала написать падающий тест, затем исправить поведение;
5. воспроизвести связанный эксперимент записанной командой.

Для этого проекта добавляется шестое: объяснить, **почему остановка в произвольный момент не
ломает гарантию** — через optional stopping и свойство мартингейла. Без этого объяснения весь
проект превращается в набор графиков.

## Как использовать AI

- сначала я пишу конструкцию, гипотезу или первый draft;
- AI задаёт вопросы, даёт подсказки и ревьюит мою попытку;
- AI может делать plumbing (конфиги, CI, обвязка прогонов), но не выводит за меня
  мартингейл и не пишет e-конструкцию;
- готовая реализация запрашивается только после моей попытки и отдельным явным решением;
- finding формулирую я после ручного QA и teach-back.

Формулировки, которые тут работают лучше всего:

- «не пиши e-value, спроси меня, что здесь мартингейл и относительно какой фильтрации»;
- «дай одну подсказку следующего уровня»;
- «проверь мой тест на контроль ошибки, не трогая реализацию»;
- «покажи контрпример на пяти наблюдениях».

## Ownership tracker

Уровни: `0` — не начинала, `1` — объясняю, `2` — меняю и тестирую,
`3` — защищаю экспериментальный вывод.

| Область | Фаза | Уровень | Моё доказательство |
|---|---|---:|---|
| мультиномиальный поток и сиды | 1 | 0 | |
| проверка доли при фиксированном N | 2 | 0 | |
| инфляция α при подглядывании | 2 | 0 | |
| мартингейл и optional stopping | 3 | 0 | |
| e-value для простой альтернативы | 3 | 0 | |
| смесь по альтернативам (composite) | 3 | 0 | |
| ARL0 и контроль ложных тревог | 3 | 0 | |
| задержка обнаружения и KL-масштаб | 4 | 0 | |
| парные интервалы на разностях | 4 | 0 | |
| цензурирование на горизонте | 4 | 0 | |
| мониторинг всей таблицы | 5 | 0 | |

Таблицу заполняет только автор проекта.
