# Reports

Результатов пока нет.

Один отчёт — на один эксперимент из `experiments/`. Отчёт появляется только после
publication gate из [research protocol](../docs/research-protocol.md): тесты корректности
зелёные (включая проверку контроля ошибки под нулём), протокол не менялся молча, посчитана
неопределённость на парных разностях, уровни ошибок методов выровнены и это показано числом.

Скорость обнаружения без измеренной доли ложных тревог рядом — не результат, а реклама.
Медиана задержки публикуется только вместе с долей потоков, где обнаружения не случилось до
конца горизонта.

Каждый отчёт содержит раздел «что не сработало»: ячейки, где эффект не воспроизвёлся,
и границы применимости. И ни один отчёт не называет конкретную игру — данных для таких
утверждений в проекте нет.
