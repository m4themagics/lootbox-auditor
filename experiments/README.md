# Experiments

Один каталог — один исследовательский вопрос, а не один метод. Метод без вопроса живёт в
`src/lba/`, а сюда попадает только то, что что-то проверяет.

```text
experiments/<nn>_<slug>/
  README.md          вопрос, гипотеза, механизм, критерий успеха
  protocol.md        заполненный research protocol — до прогона
  run.py             ровно одна команда запуска
  results/           числа, графики, run manifest
```

Запланированные вопросы по фазам:

| # | Вопрос | Фаза |
|---|---|---|
| 00 | Измерима ли цена непрерывного мониторинга в реалистичном диапазоне редкости? | 0 |
| 01 | Сходятся ли частоты симулятора к заявленной таблице и воспроизводим ли поток? | 1 |
| 02 | Насколько подглядывание раздувает долю ложных тревог и как это зависит от числа взглядов? | 2 |
| 03 | Держит ли e-детектор заявленный уровень и какой у него ARL0? | 3 |
| 04 | Как задержка зависит от редкости и размера занижения, и совпадает ли она с log(1/α)/KL? | 4 |
| 05 | Сколько стоит переход от одного предмета к мониторингу всей таблицы? | 5 |

Нумерация закрепляется в момент старта эксперимента: список выше — намерение.
